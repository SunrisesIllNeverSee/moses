# Enterprise Pilot Integration Docs

This directory captures the commercial and technical bridge between the SigRank measurement standard and the MO§ES™ enterprise pilot sold through mos2es.org.

## Files

- `SIGRANK_STANDARD_MAPPING.md` — internal telemetry/metric lineage and translation boundary.
- `ENTERPRISE_PILOT_COMMERCIAL_MAP.md` — public commercial front-face positioning and buyer journey.
- `pilot-manifest.schema.json` — machine-readable scope/handoff contract for a sold pilot.

## Governing rule

mos2es.org remains enterprise-native in public language.

SigRank compatibility is an underlying measurement/interoperability layer, not a requirement that enterprise buyers learn or see SigRank terminology everywhere.

Where the two systems use similar metric names with different formulas, the derivation namespace/version must remain explicit internally.
