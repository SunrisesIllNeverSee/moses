# Enterprise Pilot Integration Docs

This directory captures the commercial and technical bridge between Upsilon, the SigRank compatibility record, and the MO§ES™ governance framework used by the enterprise pilot sold through mos2es.org.

## Files

- `SIGRANK_STANDARD_MAPPING.md` — internal telemetry/metric lineage and translation boundary.
- `ENTERPRISE_PILOT_COMMERCIAL_MAP.md` — public commercial front-face positioning and buyer journey.
- `UPSILON_PRODUCT_ARCHITECTURE.md` — locked product roles, compatibility boundary, and EKG interpretation guardrail.
- `pilot-manifest.schema.json` — machine-readable scope/handoff contract for a sold pilot.

## Governing rule

mos2es.org remains enterprise-native in public language.

Upsilon is the product buyers see. SigRank compatibility is an underlying measurement/interoperability layer and SigRank itself is the public proof surface; neither requires enterprise buyers to learn the wire vocabulary.

Where the two systems use similar metric names with different formulas, the derivation namespace/version must remain explicit internally.
